# AutoFinder Iran — Automotive Service Directory Demo

A responsive, Persian-first (RTL) automotive directory application demonstrating search, filtering, sorting, and business detail views.

## Live demo
https://khandanian.github.io/autofinder-ira/

## Features
- Search by business name, service, city, province, or area
- Province, city, and service category filters
- Sorting by name, sample rating, and sample review count
- Responsive service cards and business detail dialogs
- Static HTML, CSS, and JavaScript; no server required

**Important:** Every business name, location association, rating, and review count is fictional demo data. This is a portfolio prototype, not a factual directory.

## Run locally
Open `index.html` in a browser, or run `python -m http.server 8080`.

## GitHub Pages
Set **Settings → Pages → Source** to **GitHub Actions**. The deployment workflow is at `.github/workflows/deploy.yml`.
